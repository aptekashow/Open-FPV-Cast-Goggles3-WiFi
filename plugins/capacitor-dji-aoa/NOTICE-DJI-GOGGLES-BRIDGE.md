The Goggles 3 Wi-Fi transport added in this project is an independent Kotlin adaptation of the
reverse-engineered DJI Goggles 3 UDP protocol documented by DJI Goggles Bridge:
https://github.com/Evols/dji-goggles-bridge

DJI Goggles Bridge is licensed under Creative Commons Attribution 4.0 International (CC BY 4.0).
This project credits Baptiste Hutteau and contributors. The Kotlin implementation is adapted for
Android and integrated with Open FPV Cast's existing H.264 fan-out pipeline. It is not affiliated
with or endorsed by DJI.
